## Problem Standard

For each problem, I aim to be able to:

- State the problem precisely
- Identify constraints
- Derive the solution
- Explain the invariant
- Implement it from scratch
- Analyze time and space complexity
- Handle edge cases
- Adapt the solution when constraints change

The goal is **understanding and problem-solving ability, not memorizing solutions**.
